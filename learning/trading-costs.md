# 交易成本：手续费、资金费与预留缓冲

## 手续费怎么算

永续合约按**成交额**收费，每边一次，开仓和平仓各收一次：

```text
单边费用 = 成交额 × 费率
往返费用 = 成交额 × 费率 × 2
```

OKX 永续的实测费率（2026-07 至 11，408 笔实盘）：

| 项 | 实测值 |
| --- | ---: |
| 开仓费率（中位） | 0.0500% |
| 平仓费率（中位） | 0.0498% |
| **往返合计** | **0.0999%** |

费率区间约 **0.03%~0.05%（3~5 个基点）**，取决于账户等级与是否挂单。实测取的是 taker 档的最高值。

个别笔会出现 0.08% 的记录值（408 笔里 1 笔），原因是市价单被拆成多次成交，记录口径与实际扣款不一致，不是费率上调。

## 为什么要预留缓冲

下单时账户必须同时覆盖**保证金 + 手续费**。如果按 100% 余额下单，手续费没有出处，交易所直接拒单（`Insufficient funds`）。

所以仓位上限要留出缓冲：

```text
实际下单 = min(目标仓位, 可用余额 × (1 − 缓冲))
```

缓冲要覆盖两件事：

1. **手续费**：单边 0.05%；
2. **成交偏离**：市价单从信号到成交有几百毫秒延迟，流动性差的币可能跳 0.1%~0.5%。

## 实盘采用的值

**缓冲 0.7%（70 个基点）。**

依据：手续费 0.05% + 实测最大成交偏离 0.03% = 0.08%，0.7% 有约 8 倍富余。

这个值只影响"能不能开出来"，不影响策略逻辑，属于执行层的安全垫，不是策略参数。

## 资金费

永续每 8 小时结算一次，多头付空头收（费率为正时）。实测 4 个月 27.16 USDT，约为手续费的 19%。

按持仓时长折算：平均每笔 0.02% 左右，比手续费小一个量级。

## 成本的量级

| 项目 | 相对每笔 EV（约 0.5%） |
| --- | ---: |
| 手续费往返 | 0.10%（约 20%） |
| 资金费 | 0.02%（约 4%） |
| **合计** | **约 24%** |

**每笔优势的四分之一被成本吃掉。** 这是高频策略的固有代价，降低换手率或改挂单成交才能改善。
