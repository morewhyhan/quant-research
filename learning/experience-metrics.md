# 交易体验的量化方法

"体感"是主观的，但可以拆成一组**可计算、可复现**的指标。本文给出指标定义、计算口径和汇总方法，用于比较不同版本的持有体验。

## 一、测量原则

1. **每个指标先写公式**，再写数值。没有公式的数字不能比较。
2. **说明口径**：按日盯市、按笔平仓，还是按小时；是否含浮盈亏。同一张表里不许混用。
3. **报分布，不报单点**。"最大回撤 23%" 只说明那一条路径；应同时给中位数和 90 分位。
4. **单条历史路径是样本之一**，不是期望值。要另做重抽样，得到"换个交易顺序会怎样"的分布。
5. **分年计算**。跨年混合会掩盖年际差异。
6. **指标之间不重复计分**。深度、持续时间、频率是三个维度，不能用一个数代替。

## 二、模块与指标

### 模块一：回撤形态

| 指标 | 定义 | 计算口径 |
| --- | --- | --- |
| 最大回撤 MDD | `max_t (1 − V_t / M_t)` | 权益曲线，按平仓时点或按日 |
| 回撤中位 | 重抽样路径的 MDD 中位数 | 见第五节 |
| 90 分位 | 重抽样路径的 MDD 第 90 百分位 | 同上 |
| **水下时间占比** | `V_t < M_t` 的时段数 ÷ 总时段数 | 按日 |
| **最长水下时长** | 连续满足 `V_t < M_t` 的最长天数 | 按日 |
| **回撤频率** | 一年内跌幅超过 10%、20%、30% 的次数 | 按走完一轮"跌破 → 收回"计一次 |
| **恢复时间** | 从谷底回到前高所需天数 | 每个回撤段落单独算，取中位与最长 |

**深度是"某一刻多痛"，持续时间是"难受多久"。** 两者必须分开，20% 回撤持续 3 天和 3 个月是完全不同的体验。

### 模块二：单笔与连败

| 指标 | 定义 |
| --- | --- |
| 最差单笔 | `min(profit_abs)` 及其占当时权益的比例 |
| **最大连败笔数** | 连续亏损交易的最长长度 |
| **连败累计亏损** | 该段连败的亏损总和占当时权益的比例 |
| 最差单日 | 按日汇总的权益变化最小值 |

连败是体验的放大器：单笔 −2% 可以接受，连续 8 笔 −2% 很难拿住。

### 模块三：收益节奏

| 指标 | 定义 |
| --- | --- |
| 月度胜率 | 正收益月份数 ÷ 总月份数 |
| 最差月 | 月度收益的最小值及发生时间 |
| 连续亏损月 | 最长连续负收益月数 |
| **创新高频率** | 相邻两次权益新高的平均间隔天数 |

"多久能看到账户创新高"直接决定持有信心。

### 模块四：资金与操作

| 指标 | 定义 |
| --- | --- |
| 平均仓位 | `mean(下单金额 / 当时权益)` |
| 满仓时间占比 | 仓位 >90% 的时段比例 |
| 交易频率 | 日均成交笔数 |
| 持仓时长 | 中位、平均、最长 |
| 保证金风险 | 1 倍杠杆下的强平距离 |

### 模块五：极端情形

| 指标 | 定义 |
| --- | --- |
| 单笔最大冲击 | 最差单笔对账户的百分比影响 |
| 极端行情表现 | 指定压力区间的收益与回撤 |
| 停机暴露 | 断网/断电时可能的最大持仓敞口 |

### 模块四（补充）：资金的可用性

前面只写了仓位占用，还缺一个更实际的问题：**这笔钱进去之后，还能不能随时拿出来。**

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| **提现自由度** | 随时可动用的资金比例 | 单持仓策略里，持仓期间 100% 被占用 |
| 持仓占用时长 | 单笔持仓的平均/最长时长 | 我们中位 75 分钟、最长 18 天 |
| 提现对策略的扰动 | 提现后仓位比例的变化 | 地板是固定金额，提现后比例会跳变 |
| 出入金成本 | 交易所提现费率与到账时间 | 与策略无关，但影响真实体验 |
| 资金锁定机会成本 | 这笔钱不能同时做别的用途 | 需要与替代收益比较 |

**关键**：随时能提现，和"提现后策略还正常"，是两件事。前者看交易所，后者看策略是否依赖账户总权益。

### 模块五（补充）：心理与行为

这一块最主观，但仍有可测的代理指标。

| 指标 | 定义 | 为什么重要 |
| --- | --- | --- |
| **浮亏时间占比** | 持仓期间处于浮亏的时长比例 | 直接对应"每天打开账户看到红的"的频率 |
| 最大浮亏 | 单笔未平仓时的最大浮亏 | 比已实现亏损更刺激情绪 |
| 回本天数 | 从投入本金算，多久回到本金 | 心理账户效应 |
| 干预冲动指数 | 交易频率 × 单笔波动 | 越频繁越容易手贱 |
| 睡眠测试 | 单日最大跌幅 | "能不能睡着"的量化版 |

### 模块六：规模与容量

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 最小起步资金 | 地板金额 | 我们 1,000 USDT |
| 容量上限 | 滑点开始显著上升的资金规模 | 需按币种流动性估算 |
| 规模衰减 | 资金翻 10 倍后收益的下降幅度 | 与市场冲击成本相关 |
| 多账户可行性 | 能否拆分到多个账户 | 受交易所限制 |

**这套策略的仓位是账户的 40%，资金越大绝对成交额越大，滑点会吃掉 EV。** 容量必须单独评估。

### 模块七：运维与外部依赖

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| **停机暴露** | 断网/断电时的最大持仓敞口 | 单持仓、最大 105% 权益 |
| 交易所单点风险 | 是否只依赖一家交易所 | 我们只用 OKX |
| 数据与接口稳定性 | 回测期间的历史故障次数 | 今天遇到多次 OKX 超时 |
| 维护窗口 | 升级策略时必须空仓的时长 | 与持仓时长相关 |
| 资金费结算时点 | 每 8 小时的费率变动 | 跨结算点持仓会有额外成本 |

### 模块八：记录与合规负担

| 指标 | 定义 | 说明 |
| --- | --- | --- |
| 年交易笔数 | 一年成交次数 | 我们约 1,000 笔/年 |
| 对账工作量 | 笔数 × 每笔需核对的字段 | 报税、审计时要能解释每一笔 |
| 策略可解释性 | 能否用一句话说清每笔的进出理由 | 影响长期信任 |

**一年 1,000 笔的交易记录，报税和对账是真实负担，不是小事。**

## 三、计算流程

1. 从回测导出逐笔成交（含 `close_date`、`profit_abs`、`stake_amount`）。
2. **重建权益曲线**：`V_0 = 本金`，`V_i = V_{i−1} + profit_abs_i`。按日聚合时取当日最后一笔的收盘权益。
3. 逐项计算上表的指标，**每个指标记录口径**（按笔还是按日）。
4. 单路径指标直接输出；分布类指标走第五节的重抽样。
5. 汇总成表：行是指标，列是版本，便于横向比较。

## 四、把指标合成一个分数（可选）

不同指标量纲不同，比较时先归一化：

```text
score_i = (x_i − min) / (max − min)     正向指标
score_i = (max − x_i) / (max − min)     反向指标（回撤类）
```

再按模块加权：

| 模块 | 建议权重 | 理由 |
| --- | ---: | --- |
| 回撤形态 | 40% | 决定能不能拿住 |
| 单笔与连败 | 30% | 决定每天的焦虑程度 |
| 收益节奏 | 20% | 决定信心 |
| 资金与操作 | 10% | 决定能不能持续执行 |

**权重要在比较之前定好**，否则会不自觉地给"结果好的版本"更高权重。

## 五、重抽样：把单条路径变成分布

单次回测只给出一个结果。要回答"换个顺序会怎样"：

1. 取逐笔收益率序列 `r`；
2. 有放回地抽取同样笔数，按顺序重放，得到一条新路径；
3. 重复 1,000～2,000 次；
4. 统计指标的分布（中位、90 分位、超阈概率）。

**注意**：重抽样假设各笔独立。若存在序列相关，会低估聚集风险；可用分块抽样（每块 20 笔）缓解。

## 六、常见陷阱

| 陷阱 | 后果 | 正确做法 |
| --- | --- | --- |
| 混用口径 | 同一张表里的数字不可比 | 每张表头写清口径 |
| 只报最大回撤 | 掩盖持续时间和频率 | 至少报深度、时长、频率三项 |
| 用单路径当期望 | 高估或低估风险 | 加重抽样分布 |
| 对数与算术回撤混用 | 深回撤时误差可达数倍 | 用 `1 − V/峰值`，不要用 `exp(峰值−当前)−1` |
| 跨年合并 | 掩盖年际差异 | 分年计算 |
| 事后定权重 | 分数服务于结论 | 比较前先定权重 |
