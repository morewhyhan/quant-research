# 回撤：从最高点跌了多少？

账户从 100 涨到 200，再跌到 100，就是从高点跌了 50%，回撤为 50%。

它不是相对最初投入的收益率。"最大回撤"是整段记录中，这种跌幅最大的一次。

比较回撤时，要说明是否算持仓浮盈亏、多久记录一次账户价值，以及怎样处理出入金。历史最大回撤不是未来最多会亏多少的保证。

相关概念见[收益、EV 与 PF](returns-and-pf.md)。

## 度量公式

设 V_t 是账户在 t 时刻的价值，M_t 是到 t 为止的最高点：

```text
回撤      DD_t = 1 − V_t / M_t
最大回撤  MDD  = max(DD_t)
```

三个常用衍生指标：

| 指标 | 公式 | 说明 |
| --- | --- | --- |
| Calmar | 年化收益 ÷ MDD | 每承受 1 单位最大回撤换来多少年化收益 |
| Ulcer Index | √(平均(DD_t²)) | 同时反映深度和持续时间，比 MDD 稳定 |
| 恢复时间 | 从谷底回到前高的时间 | 实际体验里最难受的部分 |

## 回撤和收益、波动的关系

对连续时间的资金曲线，长期最大回撤的期望值有一个简洁结果：

```text
E[MDD] ≈ σ² / (2μ) = σ / (2 × Sharpe)
```

μ 是年化对数收益，σ 是年化波动。

由此三条结论：

1. 回撤与夏普的**平方**成反比：夏普翻倍，回撤减到四分之一；
2. 回撤与波动**平方**成正比：波动翻倍，回撤变四倍；
3. 若把杠杆放大 k 倍，μ 与 σ 都乘 k，所以 `E[MDD]` 约乘 k——**回撤随杠杆线性增长**，而收益因复利略低于线性。

这条公式也解释了为什么"提高收益"和"压低回撤"通常是同一件事的两面：只能提高 μ 或降低 σ。

## 四种控制回撤的机制

### 一、仓位缩放

最直接的一类，都是改"下多少注"。

| 方法 | 公式 | 特点 |
| --- | --- | --- |
| 凯利 | f* = μ / σ² | 最大化长期增长率，不控制过程回撤 |
| 分数凯利 | f = f* / k（k 常取 2~4） | 用增长率换稳定性，实践标准 |
| 波动目标 | w = σ_target / σ_实现 | 波动升高时自动减仓，利用波动的聚集性 |

凯利假设 μ 已知。实际 μ 是估出来的，有误差，所以要用分数凯利。μ 的不确定性越大，k 取得越大。

### 二、回撤约束（Grossman–Zhou）

目标是让资金曲线**永远不低于历史最高点的某个比例**：

```text
约束：V_t ≥ α · M_t，  α ∈ (0, 1)
```

数学结论：满足这个约束的最优策略等价于买入一个回看期权，风险敞口与"离地板还有多远"成正比：

```text
敞口 ∝ V_t − α · M_t
```

工程上最常用的近似是 CPPI（固定比例投资组合保险）：

```text
地板   Floor = α · M_t
缓冲   Cushion = V_t − Floor
敞口 = m × Cushion    （并受 0 与 100% 截断）
```

它的行为：在最高点时满仓，跌向地板时自动减到 0。

和"跌 8% 就把仓位砍半"这类离散规则的区别：CPPI 是连续、平滑地减仓，而且有最优性证明；离散阈值没有理论依据，依赖"回撤可预测"这个前提。

### 三、风险预算与风险平价

有多个策略或品种时，按**风险贡献**分配，而不是按资金平均分：

```text
w_i ∝ 1 / σ_i        （简单版）
Σ_j w_i w_j σ_ij = 常数   （严格版）
```

单策略用不上；多策略组合时是标准做法。

### 四、硬约束

```text
单笔最大亏损 ≤ 账户 × 阈值
```

不改善期望，只截断尾部。常见形式是固定止损、单日最大亏损、最大持仓数。

## 怎么选

| 情况 | 用哪一种 |
| --- | --- |
| 只有一个策略，能估出 μ 和 σ | 分数凯利，取 1/4 ~ 1/2 |
| 波动有明显聚集 | 加一层波动目标 |
| 能接受"接近地板就空仓" | CPPI / 回撤约束 |
| 有多个不相关策略 | 风险平价 |
| 任何情况 | 都保留硬止损 |

**没有第三条路**：所有回撤控制最终都是在降 σ 或提 μ。任何"预测回撤然后减仓"的做法，前提是回撤可预测——这一点必须先验证，不能假设。
