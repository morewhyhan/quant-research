# BTC 24 小时收益 × 入场分支

状态：候选因子，未验证为稳定有效因子。

## 它是什么

这是一个在入场前可计算的环境变量：BTC 最近 24 小时的收益率。当前研究没有把它当作所有信号通用的买卖分数，而是检验它与 `enter_tag` 的交互：同一个 BTC 状态，对不同入场分支可能有不同含义。

定义（入场时刻为 `t`，使用最后一根已闭合的 BTC 5m K 线）：

```text
btc_ret_24h(t) = BTC_close(t - 1) / BTC_close(t - 289) - 1
```

代码中的等价计算是 `pct_change(288).shift(1)`。当前候选门控只对两个分支设置阈值：

| 入场分支 | 保留条件 | 2024 校准后的阈值 |
| --- | --- | ---: |
| `short_new` | `btc_ret_24h >= threshold` | +1.5405% |
| `buy_1` | `btc_ret_24h >= threshold` | −3.0291% |

其他分支暂不使用该门控，缺失值不放行受门控分支。

## 当前判断

它可以作为“条件因子候选”，不能称为已经验证的通用因子：

- `short_new` 在 2024、2025、2026 的接受组平均收益都高于阻断组，方向一致；但样本很小，按时间簇 bootstrap 的 95% 区间都跨过 0。
- `buy_1` 在 2024、2025 为正，2026 反转为负，且被阻断样本很少，暂时不能声称稳定。
- 连续值与收益的 Spearman 相关接近 0，尚未支持“BTC 24h 收益越高，策略收益就单调越高”的说法。
- 完整 Freqtrade 重跑中门控结果更好，但过滤会改变持仓容量和后续替代交易，不能把账户改善直接归因成独立因子 alpha。

因此，研究名义应写成“BTC 环境 × 入场分支的条件门控候选”，而不是“BTC 24h 动量因子已验证有效”。

## 使用边界

- 只能使用入场前已闭合 K 线，不能使用 MFE、MAE、退出原因或最终收益。
- 阈值必须在训练区间冻结，再用未参与选参的 forward 区间检验。
- 评估必须同时跑：完整组合回测、分支增量效果、成本/滑点、容量和替代交易；不能只从已成交表删除坏单。
- 本目录的 `factor.py` 是研究定义的单一真源；它尚未自动改写实盘策略。
