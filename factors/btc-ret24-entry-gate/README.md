# BTC 24 小时收益 × 入场分支

状态：候选因子，未验证为稳定有效因子。

## 先用一句话说清楚

这个因子回答的问题不是“现在应该买还是卖”，而是：**当 V26 已经产生某个入场信号时，BTC 最近 24 小时的整体环境，是否足以让这个信号继续进入交易执行？**

它是一个“入场前环境变量”，再和入场分支组合成一个门控条件：

```text
行情数据
  -> 计算 btc_ret_24h
  -> 查看 enter_tag
  -> 按该分支的阈值判断
  -> 放行入场，或阻断入场
```

所以要严格区分：

- `btc_ret_24h` 是因子候选：它是一个在决策前能计算出来的数字。
- “大于某个阈值才放行”是使用因子的交易规则。
- “回测变好”是结果，不是因子定义，也不代表因果关系已经证明。

## 它到底是什么

入场时刻为 `t`，使用入场前最后一根已闭合的 BTC 5m K 线：

```text
btc_ret_24h(t) = BTC_close(t - 1) / BTC_close(t - 289) - 1
```

代码中的等价计算是 `pct_change(288).shift(1)`。例如结果是 `0.02`，表示 BTC 在此前约 24 小时上涨 2%；结果是 `-0.03`，表示下跌 3%。

它不是交易所直接提供的“强弱等级”，也不是一个神奇的预测分数，只是从历史行情计算出来的环境描述。

## 它是怎么挖出来的

这次不是把几百个指标穷举一遍后挑最高收益，而是从 V26 的亏损结构倒推：

1. 先把交易按 `short_1`、`short_new`、`buy_1`、`buy_new` 分开，发现 `short_new` 的亏损尾部更重，`buy_1` 也有明显的环境差异。
2. 只保留入场前能看到的字段，建立每笔交易的开仓快照。MFE、MAE、退出原因和最终收益被排除，因为它们发生在入场之后，不能拿来制造入场因子。
3. 检查 BTC 和币自身的 1h、4h、24h 收益、均线距离、波动率等环境变量在不同入场分支中的分布差异。
4. 发现 `btc_ret_24h` 与入场分支有交互：同一个 BTC 状态对 `short_new`、`buy_1` 的含义不同。
5. 用 2024 年的分桶结果形成候选边界，再冻结边界，检查 2025 和 2026；没有在后两个年份继续调阈值。

因此，它目前是一个**有明确来源的、假设驱动的条件因子候选**，不是经过无数次试验后被挑出来的“最优指标”。

## 它实际改变了什么

它不改变 K 线，不改变收益计算，也不直接改变止损或仓位。它只改变一个地方：**已有入场信号能不能被送进交易引擎**。

当前规则是：

| 入场分支 | 放行条件 | 不满足时发生什么 |
| --- | --- | --- |
| `short_new` | `btc_ret_24h >= +1.5405%` | 阻断该次做空信号 |
| `buy_1` | `btc_ret_24h >= -3.0291%` | 阻断该次做多信号 |
| 其他分支 | 不使用该因子 | 保持原策略行为 |

这意味着它会影响：

- 交易数量：部分信号不再开仓；
- 胜率、平均收益和亏损尾部：被阻断的信号集合发生变化；
- 持仓容量：原来被坏信号占用的持仓位可能空出来；
- 后续交易：释放的容量可能让后面的另一个信号进入，因此不能只把结果理解为“删掉坏单”。

它不会自动影响：

- 已经开仓的交易；
- `loss_half_recovery` 等退出逻辑；
- 每笔仓位大小；
- 没有使用它的其他入场分支。

## 当前证据能说明什么

`short_new` 在 2024、2025、2026 的接受组平均收益都高于阻断组，方向一致；但样本很小，时间簇 bootstrap 的区间都跨过 0。

`buy_1` 在 2024、2025 为正，2026 反转为负，而且被阻断样本只有 10—12 笔，不能称为稳定。

连续值与收益的 Spearman 相关接近 0，所以当前没有证据支持“BTC 24h 收益越高，策略收益就单调越高”。更合理的解释是：**这个变量只在某些入场分支中提供环境过滤信息**。

## 适用范围

当前结论只适用于以下边界：

- V26 这套入场逻辑及其 `enter_tag` 分支；
- 入场前、已闭合的 BTC 5m K 线；
- 当前研究使用的 OKX USDT 合约、交易池和时间尺度；
- 作为入场门控，而不是退出、仓位或收益归因因子。

换成别的策略、别的周期、别的交易池、别的交易所或新的执行规则后，必须重新验证。不能因为名称叫 BTC 24h，就把它直接复制给所有策略。

## 当前不应下的结论

- 它不是已经验证的通用 alpha 因子。
- 它不是 BTC 价格对策略收益的因果证明。
- 它不是“开关一加，回撤就一定下降”的保证。
- 它不能只靠已成交交易过滤来证明，必须观察被阻断后的替代交易和完整账户路径。
