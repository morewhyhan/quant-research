# Quant Research

量化研究仓库。用来研究问题、编写策略、运行实验和保存结论；真实行情、账户配置和完整结果仍放在私有区。

[怎样使用](仓库使用说明.md) · [研究目录](research/README.md) · [运行命令](tools/commands.md)

AI 开始任务前先读 [AGENTS.md](AGENTS.md)。

## 研究结构

仓库按**金字塔**组织：一份文档只做一件事，从上往下一层一层读。

```text
第 0 层  README.md（本文件）              仓库是什么、从哪进
          │
第 1 层  research/README.md               有哪些研究（一项一行）
          │
第 2 层  research/<研究>/report.md        这项研究的结论 + 实验表
          │
第 3 层  research/<研究>/experiments/     一次实验：命令、数据、数字、结论
          │   run-XXX/experiment.md
第 4 层  策略代码、参数、原始结果
```

策略侧同样一层一层：

```text
strategies/README.md                      有哪些策略族
  └─ e0v1e/README.md                      这族的版本谱系与代码位置
      └─ v26-2x2/README.md                类清单（目录导航）
          ├─ rules.md                     仓位与退出定义
          ├─ params.md                    参数、预检、复现、数据位置
          └─ variants.md                  30 个变体：改动 → 结论 → 实验
```

三条规矩：

1. **每份文档一个职责**。研究结论只写在报告里，实验数字只写在实验记录里，策略说明只写在策略目录里，不互相抄。
2. **只能从上一层进下一层**。想找某次实验的结果，走 研究 → 报告 → 实验，不要在策略文档里找业绩。
3. **新增内容先归位**。新研究进 `research/`，新实验进该研究的 `experiments/`，新策略类进 `strategies/<族>/<版本>/` 并登记到变体表。

## 怎样配合？

一项研究先写清问题，再引用具体策略、因子和数据。每次实验保存自己的设置与结果，最后在报告中说明结论，过程较长时另写笔记。

研究目录只列入口，不堆正文。同一个问题换策略或年份，通常继续用原项目；重跑实验建新记录，不覆盖旧结果。

研究目录已记录 V26 信号分离、回测与实盘差距、真突破与慢性大亏三项研究；策略目录包含其四组 2×2 研究版本。模板文件规定怎么填写；通用工具和人工测试数据用于检查流程，研究回测不代表未来交易业绩。

新建时只增加需要的文件，不预填案例、收益表或服务器状态。已有工具能做什么，见[工具说明](tools/README.md)。
