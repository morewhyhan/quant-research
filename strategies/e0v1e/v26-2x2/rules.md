# 仓位与退出定义

## 四个冻结版本的定义

| 策略类 | 仓位 | `loss_half_recovery` |
| --- | --- | --- |
| `E0V1E64_V26_GATED_DYNAMIC_RECOVERY` | 动态滚仓 | 开启 |
| `E0V1E64_V26_GATED_DYNAMIC_NO_RECOVERY` | 动态滚仓 | 关闭 |
| `E0V1E64_V26_GATED_FIXED_RECOVERY` | 每次最多 1,000 USDT | 开启 |
| `E0V1E64_V26_GATED_FIXED_NO_RECOVERY` | 每次最多 1,000 USDT | 关闭 |

四个版本必须使用相同的交易池、时间区间、费用、杠杆、最大持仓数和参数文件。不要把 `ENVGATE` 再作为第五个独立变量混入这组比较。

## 固定仓位

```python
stake = min(1000, max_stake)
```

账户可用资金超过 1,000 时，下一笔仍最多使用 1,000；低于 1,000 时，使用 Freqtrade 允许的剩余金额。固定的是每笔 USDT 目标金额，不是账户百分比。

## 动态仓位

沿用 V9 的动态仓位函数，仓位随可用账户资金和回撤状态变化。

## 恢复退出

持仓历史最差收益达到 −5% 后，当前收益回到最差值的一半时，返回 `loss_half_recovery`。无恢复版本不执行这一条，其他退出保持不变。

### 仓位

```text
基础仓位 = min( max(1000, 40% × 当前权益), 可用余额 )
实际仓位 = 基础仓位 × 波动系数 × 区间系数，再与可用余额取小
```

波动系数（用上一根已收盘 K 线的 ATR/收盘价，按区间匹配）：

| ATR% 区间 | 系数 |
| --- | ---: |
| < 0.6 | 0.55 |
| 0.6 – 0.9 | 0.85 |
| 0.9 – 1.2 | 1.00 |
| **1.2 – 1.6** | **2.40** |
| 1.6 – 2.0 | 1.75 |
| ≥ 2.0 | 1.00 |

区间系数（仅空单，用上一根已收盘 K 线计算价格在 24 小时区间的位置）：

| 位置 | 系数 |
| --- | ---: |
| < 20% | 1.50 |
| > 80% | 1.30 |
| 其余 | 1.00 |

### 退出

| 规则 | 值 |
| --- | --- |
| 硬止损 | −25%（JSON `stoploss`） |
| 恢复退出 | 浮亏曾达 −5% 后，回到最差值的 **1/3** 即平仓（`recovery_divisor = 3.0`） |
| 其余退出 | 与 V26 相同（fastk、V5 延长、MA120、CCI） |

### 参数与配置

| 项 | 值 |
| --- | --- |
| 参数文件 | `E0V1E64_V26_F40_FINAL.json`，`params` 与生产 V26 完全一致 |
| 关键参数 | `buy_rsi_fast_period=183`、`buy_rsi_period=47`、`buy_rsi_slow_period=81`、`short_cti_32=−0.66`、`stoploss=−0.25` |
