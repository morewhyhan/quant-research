# `short_1` BTC 环境因子：软仓位调节

研究类型：factor（因子）+ portfolio robustness（组合稳健性）

状态：完成（2026 账户级结果不足以证明有效）

前次实验：[run-009 `short_1` 硬过滤](../run-009-short1-regime/experiment.md)；关系：改规则。前次把信号阻断，本次只改变仓位。

## 研究问题

前次的单笔统计显示，BTC 过去 24 小时收益低于 `+0.4153%` 时，`short_1` 的平均收益和 Profit Factor 较弱。但把这些信号硬过滤后，完整账户回测反而从 920 笔降到 534 笔，收益和 PF 都下降。

本次测试一个更保守的使用方式：

```text
BTC 24h 收益 >= +0.4153%  -> short_1 使用原仓位
BTC 24h 收益 <  +0.4153%  -> short_1 使用原仓位的 50%
其他入场分支             -> 不改变
```

它不阻断信号，不改变 `max_open_trades=1`，也不改变止盈、止损和退出规则。目的不是再调一个最优比例，而是检查该变量能否作为风险暴露调节器。

## 账户级结果

| 指标 | 原 V26 | 软仓位候选 | 变化 |
| --- | ---: | ---: | ---: |
| 交易数 | 920 | 918 | −0.2% |
| 最终余额 | 89,982.10 USDT | 36,501.63 USDT | −59.4% |
| 收益率 | +1,024.78% | +356.27% | −668.51 个百分点 |
| 胜率 | 旧摘要未保存 | 74.18% | 仅作候选记录 |
| Profit Factor | 1.22 | 1.234 | +0.014 |
| 账户最大回撤 | 45.27% | 43.62% | −1.65 个百分点 |
| 最差单笔 | 旧摘要未保存 | −25.07% | 仍存在极端尾部 |

仓位调节确实让账户回撤略有下降，PF 也小幅提高，但代价是复利收益大幅下降；它没有证明 BTC 24h 变量能带来新的正收益，只说明“弱环境少承担风险”在这一段历史上有轻微的风险抑制效果。

## 判断

这不是一个已经有效的 alpha 因子。若验收标准是“在不明显牺牲收益的情况下提高实盘 PF、缩小实盘与回测差异”，本次未通过：

1. 硬过滤版本的收益和 PF 变差，说明单笔筛选不能直接转成账户规则；
2. 软仓位版本只改善 1.65 个百分点的账户回撤，却牺牲 668.51 个百分点的历史收益率；
3. 结果只覆盖 2026 一个完整账户区间，不能据此声称跨年份稳定；
4. 本地数据仍缺部分资金费／标记价历史，并有数据结束时间和部分价格跳变警告，尚未加入真实成交滑点。

因此把它定级为：**条件风险调节候选，不是可部署的有效因子**。现阶段不能用它提高杠杆，也不能据此替换实盘策略。

## 下一步

如果继续，下一轮不应在这个阈值和 50% 比例上继续试到最好，而应做预先登记的验证：

1. 固定阈值和仓位映射，在 2024、2025 做完整账户复跑；
2. 用独立 forward / paper trading 记录信号时的 BTC 24h、原始仓位、实际仓位、资金费和滑点；
3. 预先写明通过标准：PF、最大账户回撤、收益保留比例和置信区间同时满足，不能只挑最好的一年；
4. 若仍失败，归档该候选，不再把它称为因子，转向能解释实盘成交差异的执行质量变量。
