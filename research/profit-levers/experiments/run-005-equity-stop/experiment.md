# 阶段 4：单笔权益止损

状态：完成（否）。

## 这次要查什么？

原来的止损是价格百分比（−15%／−25%），与账户大小无关。改成权益百分比后，止损会随仓位自动收紧或放松：小账户时很紧，大账户时很松，理论上能压住尾部。

## 用什么代码和数据？

- 变体：`E0V1E64_V26_FLOOR25_CD6_ES2`、`_ES3`，用 `equity_stop_common.EquityStopMixin` 覆盖 `custom_exit`。
- 判定：`当前收益率 × 仓位 / 权益 ≤ -阈值` 即平仓。
- 数据：2025 与 2026，5m，198 对。本金 1,000，单持仓，1 倍杠杆。

## 问题与决定

**收益 −34% 到 −92%，回撤反而更大，两年全部否。**

原因：这套策略的亏损单本来就是靠"扛一下再回来"——恢复退出专门等浮亏收窄才走。在 −2%~−3% 权益处硬砍，等于在噪音里止损，把会回来的单子砍在最低点（胜率 75% → 58~70%）。频繁小止损累积成连续亏损，比原来"少数几次深亏"更伤。

**这条否掉意味着：尾部不能靠"更早离场"来压。** 想压尾部只能改仓位（f）或改信号质量。

**未执行。** 与恢复退出的阈值组合、只在权益创新高后启用。
