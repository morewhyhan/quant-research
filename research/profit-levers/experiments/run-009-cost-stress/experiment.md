# 成本压力测试

状态：完成。

## 这次要查什么？

回测原本只按 0.05% 手续费计算，没有滑点。freqtrade 没有独立的滑点模型，业界做法是把滑点并进手续费（两者都按名义金额、按边计费，效果等价）。

- 基准：0.05%（OKX VIP 0 的 taker，已核实）；
- 加 2bp 滑点：0.07%；
- 加 5bp 滑点：0.10%。

## 用什么代码和数据？

- 配置：`config-2x2-fee007.json`（0.07%）、`config-2x2-fee010.json`（0.10%），其余与基准相同。
- 数据：2025 与 2026，5m，198 对。
- 本金 1,000，单持仓，1 倍杠杆。

## 问题与决定

**每边 2bp 滑点吃掉 7~16% 的收益，5bp 吃掉 14~22%。**

**PF 会跌破 1.5。** 加 2bp 后 2026 的 PF 是 1.453，加 5bp 后两年都在 1.46 左右。之前"PF 1.5 以上"的结论，前提是"零滑点"。

回撤没有明显恶化（18.9%~22.9%），说明成本主要吃收益，不放大风险。

**结论**：实盘的真实预期应写成 PF 1.45~1.55、收益 500~650%、回撤 19~23%；做到 VIP 或部分 maker 可以显著改善。
