# 固定＋恢复的统计画像

状态：完成

## 这次要查什么？

四个问题：

1. 单笔收益的分布长什么样，风险集中在哪；
2. 收益来自哪个方向、分支、退出原因和持仓时长；
3. 两年之间、前后半段之间是否稳定，是否存在序列相关；
4. 在这些统计之上，凯利和复利前沿大概在什么位置。

不改入场、退出、仓位或参数，只读已有的两份结果包。

## 问题与决定

**分布不是正态。** 偏度 −2.294、超额峰度 10.248，左尾厚。用均值和标准差描述时，必须同时给出分位数。

**收益高度依赖持仓时长。** 3 小时以内 1,453 笔赚 16,625 USDT，3 小时以上 449 笔亏 7,491 USDT。这条是后续优化的主要入口。

**恢复退出是成本项。** 它贡献 −9,163 USDT，相当于总利润的 100%；它的价值体现在回撤，不在收益。

**凯利远高于可行域。** 即使按 5% 分位的连续凯利 2.65 算，也超过可执行的 1 倍。仓位决策只能按回撤预算做。

**未执行。** 没有对 2027 或未参与数据做验证；没有把资金费、滑点和延迟加入统计；bootstrap 假设按日聚类，未处理同日多笔之间的相关性。
