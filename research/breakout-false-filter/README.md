# 真突破与慢性大亏研究

## 先看什么

- [研究结论](report.md)
- [过程与决定](notes.md)

## 研究问题

1. 真突破和假突破能否区分；
2. 慢性大亏到底是什么结构；
3. 能否在开仓前或开仓后提前识别并避免。

## 最终结论

- 真突破是负期望，但只占大亏约 20%；
- 慢性大亏占大亏约一半，是“几乎没有 MFE、长期单方向不利”的路径结构；
- 开仓前用 K 线、价格行为、资金费率，AUC 都在 0.47–0.51；
- 简单开仓后提前退出会误杀大量好单；
- 当前最大卡点是缺订单流/盘口/OI 数据。
