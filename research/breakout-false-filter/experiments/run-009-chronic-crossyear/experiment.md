# 实验 9：慢性大亏跨年市场状态模型

状态：失败

## 关系

父研究：`research/breakout-false-filter`
前序：run-008

## 目的

用 2024-2025 训练、2026 2×2 测试，加入 BTC 收益/MA/ADX/ER/波动和信号簇，检验开仓前识别慢性大亏。

## 数据

- 训练：2024-2025，1,489 笔，其中慢性 129 笔
- 测试：2026 2×2，717 笔，其中慢性 55 笔
- 慢性标签：亏损 ≤ -1%，非真突破，不利 bars ≥ 70%，最长连续不利 ≥ 10，MFE ≤ 0.5%

## 结果

- AUC：0.475–0.484
- 阈值 0.5：阻断约 583 笔，抓到慢性 48/55，但误杀好单 535 笔
- 阈值 0.6：抓到慢性 1–12 笔，误杀 72–206 笔

## 结论

失败，且比只用价格/MA 特征更差。加入 BTC 市场状态后没有形成跨年稳定信号。

## 说明

- 2026 内部时间切分曾得到 AUC 0.72，但测试慢性只有 16 笔，不能外推。
- 当前样本和特征不足以做开仓前慢性大亏过滤。

## 下一步

- 扩大数据：更多年份、更多交易对、更多慢性样本；
- 增加资金费率、OI、山寨宽度、订单流；
- 若开仓前仍不可分，研究开仓后前 6–12 根 bars 的路径预警。
